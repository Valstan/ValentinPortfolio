# #057 — отчёт одной строкой и доказательства

**Серверной поверхности нет (Next.js static export, бэкенда и API нет), секретов в
репозитории и CI нет, форм ввода нет; снаружи проверено: 301 с http, листинга каталогов
нет, служебные пути не отдаются.**

Проверено 07.10.2026, по одному запросу с паузой (залп из полсотни запросов с этой машины
даёт ложные 000). Каждому «пусто» предшествует непустой контроль тем же инструментом.

| Что | Как | Результат |
|---|---|---|
| Редирект http→https | `curl -sI http://<домен>/` | `301`, `Location` — https-адрес того же пути |
| Контроль «клиент вообще доходит» | `curl` на `/` и `/robots.txt` по https | `200` и `200` |
| Листинг каталогов | `/_next/`, `/shots/` | `403` (индекса нет, содержимое не перечисляется) |
| Служебные пути | `/.git/config`, `/.env`, `/assets/` | `404` у всех трёх; несуществующий путь тоже `404` |
| Формы ввода, прод | HTML главной: `<form`, `<input`, `<textarea`, `<select` | 0; контроль — `<a ` находится |
| Формы ввода, исходники | тот же шаблон по `web/**/*.{ts,tsx}` | 0; контроль — `<a ` и `<button` находятся |
| Секреты в репо | gitleaks по полной истории (`fetch-depth: 0`, `--redact`) в job `gates` | последние прогоны CI на `pull_request` — success |
| Секреты вне репо | `gh secret list` | семь секретов деплоя, все только в GitHub `secrets`, `gh variable list` пуст |

Что считаем «формой»: единственный интерактивный экран — конструктор техзадания
(`/tehzadanie/`) — собирает черновик из кликов и ссылки `#tz=…`; свободного текста нет
намеренно, на сервер ничего не уходит.

**Честные оговорки (не дефекты, но строкой, чтобы не пряталось):**

- Заголовки безопасности (HSTS, `X-Content-Type-Options` и т. п.) в ответе **не
  выставлены**, `Server` показывает версию. Это настройка на стороне площадки, не репо:
  править нечем, а поверхность для атаки у статики нулевая. Если Мозг сочтёт нужным —
  предложение к площадке, а не к нам.
- С машины сессии `curl` по https падает с `CRYPT_E_REVOCATION_OFFLINE` (проверка
  отзыва сертификата в Windows недоступна, не сам сертификат) — пришлось
  `--ssl-no-revoke`. Это про клиента, не про сайт; пометка на будущее для тех, кто
  проверяет с этой машины.
