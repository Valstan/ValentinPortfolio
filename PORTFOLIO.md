# Валентин — full-cycle разработчик

Проектирую, пишу и вывожу в прод рабочие продукты целиком: от настольной ERP для завода до кластера городских сайтов и Python-сервисов, которые сами собирают, отбирают и публикуют новости. Веду проект end-to-end — архитектура, фронтенд и бэкенд, база данных, CI/CD и эксплуатация на российских VPS. Ниже — системы, которые уже работают в проде, с честными статусами и планами.

**Сайт-визитка:** [валентин.вмалмыже.рф](https://валентин.вмалмыже.рф/)

## Что умею — классы задач

- **Настольные ERP-системы (Electron + Node.js).** Offline-first десктоп-клиент с локальной базой SQLite и синхронизацией на центральный PostgreSQL, печать документов с подписями, автообновление у всех пользователей разом, отказоустойчивый прод (primary + secondary на systemd/nginx).
- **Сайты и порталы (Next.js 15 + Payload CMS).** Редактируемые заказчиком сайты с админкой и on-site-редактированием прямо на странице, полнотекстовый поиск на PostgreSQL, SEO/GEO-разметка (JSON-LD, `/llms.txt`) под поисковики и ИИ-ассистентов.
- **Python-сервисы автоматизации (FastAPI + Celery + Redis).** Мониторинг тысяч источников, ИИ-отбор контента, автопубликация по расписанию сразу в несколько каналов, фоновые очереди задач.
- **Мобильные PWA с push-уведомлениями.** Устанавливаемые веб-приложения без публикации в сторах, офлайн-режим, web-push с разделением по платформам (iOS APNs / Android FCM + VAPID).
- **Аутентификация, безопасность, 152-ФЗ.** Единый вход (SSO/OIDC «Радар-ID» на базе VK ID), ролевая авторизация с первого дня, встроенные менеджеры секретов, соответствие закону о персональных данных (в т. ч. детские данные) с incident-playbook для РКН.
- **Инфраструктура и доставка.** CI/CD на GitHub Actions, деплой по SSH на systemd + nginx, HTTPS с автопродлением, кириллические домены (punycode), кластеры сайтов на одном сервере под лимитом памяти.

## Флагманы

### Матрица РМЗ

*Настольная ERP-система для ремонтного завода двигателей*

**Что даёт.** Единая учётная система завода по ремонту двигателей: заказы, склад, наряды и отчёты в одной базе вместо разрозненных таблиц и бумаги. Программа ставится на компьютеры завода и работает даже без интернета, а затем сама синхронизирует данные с общим сервером. Есть печать нарядов с подписями и автообновление клиента у всех пользователей.

**Под капотом.**
- Настольный клиент на Electron + React с локальной SQLite; синхронизация с центральным PostgreSQL через собственный журнал транзакций (ledger) с шифрованием.
- Гибкая EAV-система атрибутов — новые поля у сущностей добавляются без миграций базы.
- Автообновление: сборка Windows-инсталлятора в GitHub Actions и раздача обновлений через ledger.
- Отказоустойчивый прод: два инстанса бэкенда (primary + secondary) на systemd + nginx.

**Стек:** TypeScript; Electron + React 18 (клиент), Node 22 + Express (сервер); PostgreSQL 16 / SQLite, Drizzle ORM; pnpm-монорепо.
**Прод:** [195.161.41.30](https://195.161.41.30/) · **Статус:** в проде.
**Планы:** продолжается многоэтапное упрочнение безопасности (мультиагентный аудит, критичные дыры уже закрыты на проде); отдельной нитью — визуальный конструктор интерфейсов (UI-builder).

### Сарафан

*Автоматизированная редакция: сбор новостей из ВКонтакте, ИИ-отбор и публикация по расписанию*

**Что даёт.** Система сама собирает новости из сообществ ВКонтакте, отбирает нужное с помощью ИИ и публикует по расписанию сразу в несколько каналов (ВКонтакте, Telegram, сайты). Автоматизирует работу редакции сразу для десятков региональных новостных каналов. Дополнительно служит общим сервисом для соседних проектов: единый вход (SSO «Радар-ID») и шлюз к ВКонтакте.

**Под капотом.**
- Мониторинг 1000+ сообществ ВКонтакте: сбор, фильтрация и хранение постов.
- ИИ-анализ контента (Groq API с резервным отбором по ключевым словам) для отсева нерелевантного.
- Автопубликация по расписанию в ВКонтакте / Telegram / WordPress; фоновые задачи на Celery + Redis.
- Роль общего сервиса экосистемы: VK-шлюз для соседних проектов и провайдер входа «Радар-ID» (OIDC/SSO).

**Стек:** Python 3.12, FastAPI, Celery + Redis, PostgreSQL, интеграция с VK API; деплой SSH + systemd.
**Прод:** [вход.вмалмыже.рф](https://вход.вмалмыже.рф/) — публичная поверхность единого входа и [каталог сервисов](https://вход.вмалмыже.рф/services) · **Статус:** в проде.
**Планы:** перевод HITL-классификатора (человек-в-петле) из теневого режима в боевой; подключение остальных проектов экосистемы к единому входу.

### Гоньба

*Сайт-CMS для населённого пункта: новости и материалы под управлением редактора*

**Что даёт.** Сайт локального сообщества с новостями и страницами, которыми легко управлять: редактор правит тексты прямо на странице, а часть контента автоматически подтягивается из группы ВКонтакте. Сайт заточен под поисковики и ИИ-ассистентов, чтобы его находили. Подходит для местного СМИ, блога или информационного портала.

- SEO/GEO-пакет: JSON-LD серверными компонентами, `/llms.txt` и robots — оптимизация под поисковики и ИИ-ботов.
- Автосинхронизация контента из ВКонтакте и отказоустойчивый рендер (ISR не кэширует пустую страницу при сбое БД).

**Стек:** Next.js 15 + Payload CMS, TypeScript, PostgreSQL, pnpm 10; деплой SSH systemd + nginx, CI/CD на GitHub Actions.
**Прод:** [гоньба.рф](https://гоньба.рф/) · **Статус:** в проде.
**Планы:** веб-аналитика с согласием пользователя (Яндекс.Метрика + LiveInternet по флагу) и опечатко-устойчивый поиск (FTS на pg_trgm).

### Тренер

*Координатор детской футбольной школы: расписание, объявления и подтверждения от родителей*

**Что даёт.** Решает вечную боль школы «родители не в курсе изменений». Тренеры ведут расписание своих групп и рассылают объявления, родители получают уведомления и подтверждают, что прочитали. Тренер сразу видит, кто заметил («приняли N из M»), а администратор управляет структурой — филиалами, группами, тренерами и детьми. Из приложения одной школы выросло в платформу сети филиалов, которую может использовать школа в любом городе.

**Под капотом.**
- Клиент — устанавливаемое PWA (манифест, service worker, офлайн-режим), без публикации в сторах.
- Пуши с делением по платформам (iOS APNs web-push / Android FCM + VAPID); доставка best-effort, а гарантия покрытия — через внутреннюю очередь «непринятых» и метрику охвата.
- Соответствие 152-ФЗ по детским данным заложено с первого дня: согласие, РФ-локализация, минимизация, incident-playbook для РКН.
- Серверная авторизация по ролям с первого дня, онбординг по magic-link/инвайтам и единый вход через «Радар-ID» (VK ID).

**Стек:** Next.js 15 + Payload CMS 3.75 + React 19 + PostgreSQL, клиент — PWA; web-push (iOS APNs / Android FCM + VAPID); РФ-хостинг.
**Прод:** [интер.вмалмыже.рф](https://интер.вмалмыже.рф/) · **Статус:** в проде (первый прод-релиз запущен 26.06.2026; развёрнут в платформу сети филиалов с ролями владельца, администратора, тренера и родителя).
**Планы:**
- Полноценный чат «тренер ↔ родители» (сейчас суррогат «вопрос тренеру»).

## Планы развития и сотрудничество

Я развиваю не набор разрозненных сайтов, а связную экосистему: общий стек, единый вход «Радар-ID» (SSO поверх VK ID), общий VK-шлюз и переиспользуемые решения. Благодаря этому новый событийный или муниципальный сайт стартует за дни, а не за недели, и ложится в тот же дешёвый в сопровождении кластер. Ближайшие направления — довести муниципальные каркасы до наполненных контентом сайтов, продолжить упрочнение безопасности флагманов и расширить единый вход на все проекты.

**Чем могу быть полезен:**
- **Сайты и порталы под ключ** на Next.js 15 + Payload CMS: СМИ, события, учреждения, корпоративные — с самостоятельным управлением через админку, SEO/GEO и переносом со старого WordPress без потери позиций.
- **Настольные учётные системы (ERP)** на Electron + Node.js для производства и склада — offline-first, синхронизация, печать документов, автообновление.
- **Сервисы автоматизации** на Python (FastAPI + Celery): мониторинг источников, ИИ-отбор и публикация контента по расписанию.
- **Мобильные PWA с push-уведомлениями** и вход через VK ID, с соблюдением 152-ФЗ там, где это критично.
- **Инфраструктура и вывод в прод** на российских VPS: CI/CD, HTTPS, кириллические домены, отказоустойчивость.

Работаю честно и по факту: у каждого проекта выше — реальный статус и открытые планы, без приукрашивания. Обсудить задачу можно через сайт-визитку: [валентин.вмалмыже.рф](https://валентин.вмалмыже.рф/).
