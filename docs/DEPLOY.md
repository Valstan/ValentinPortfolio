# Деплой валентин.вмалмыже.рф

> ⚠️ Репозиторий публичный. В этом файле **нет** хостнеймов, портов, путей и имён SSH-алиасов —
> они живут в секретах GitHub и в `access/INDEX.md` Мозга. Здесь только процедура и грабли.

## Схема

Static export (`web/out/`) собирается **в CI** и заливается rsync'ом на бокс, где nginx отдаёт
каталог напрямую. RAM на сервере ≈ 0: сборка на боксе запрещена (G20 — `next build` там ловит OOM).

Релизы кладутся рядом (`release-<UTC-таймстамп>`), затем симлинк `current` атомарно
переключается на новый; хранятся три последних — откат = переключить симлинк назад.

## Секреты репозитория (Settings → Secrets → Actions)

| Имя | Что это |
|---|---|
| `DEPLOY_SSH_KEY` | приватный ключ **отдельной** пары, выданной только под этот репозиторий (#001) |
| `DEPLOY_KNOWN_HOSTS` | вывод `ssh-keyscan` целевого хоста — без него деплой идёт вслепую |
| `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_PORT`, `DEPLOY_PATH` | координаты цели |
| `SITE_URL` | публичный адрес для смоука, **в punycode** |

Ключ деплоя ограничивается на стороне сервера `command=`/`from=` в `authorized_keys` —
он не должен давать shell шире, чем нужно для rsync.

## Домен и HTTPS

- Домен кириллический → **в конфигах и всех абсолютных URL только punycode**
  `xn--80adkmnnb2b.xn--80adkdyec4j.xn--p1ai` (G133/G134: юникод-хост ломает сниппет при шаринге в ВК).
- **HTTPS включается в панели хостинга** (Домены → SSL → бесплатный сертификат), а не certbot'ом на боксе:
  без выделенного IP внешние 80/443 терминирует прокси хостера, свой nginx:443 снаружи недостижим (G150).
- Редирект http→https на боксе — **только по `$http_x_forwarded_proto`**, не по `$scheme`:
  по `$scheme` получается петля перенаправлений (G150).

## nginx (шаблон, значения подставляются на боксе)

```nginx
server {
    listen 80;
    server_name xn--80adkmnnb2b.xn--80adkdyec4j.xn--p1ai;

    # G150: судить о протоколе только по заголовку от прокси хостера
    if ($http_x_forwarded_proto = "http") {
        return 301 https://$host$request_uri;
    }

    root /<путь>/current;
    index index.html;

    # trailingSlash: true в next.config → каталоги с index.html
    location / {
        try_files $uri $uri/ $uri/index.html =404;
    }

    error_page 404 /404.html;

    location ~* \.(?:jpg|jpeg|png|webp|avif|svg|ico|woff2)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # HTML не кэшируем надолго — иначе релиз не виден до истечения кэша
    location ~* \.html$ {
        add_header Cache-Control "public, max-age=300";
    }
}
```

## Что проверяет CI после деплоя (#011)

Смоук грепает **маркер в теле ответа**, а не код 200: у статики 200 отдаёт и пустой индекс.
Проверяются главная (подпись автора + JSON-LD), `robots.txt`, `llms.txt`, каталог работ.

## Перед первым go-live

1. Завести DNS-запись поддомена (у остальных сайтов кластера wildcard уже резолвится).
2. Включить сертификат в панели хостинга, дождаться выпуска.
3. Создать на боксе целевой каталог и `authorized_keys` для деплой-ключа.
4. Заполнить секреты репозитория.
5. Запустить workflow вручную (`workflow_dispatch`) и убедиться, что смоук зелёный.
6. Отправить в `mailbox/to-brain/` ack go-live + карточку для каталога сервисов.
