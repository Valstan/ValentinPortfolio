## Грабли этой сессии (уже вылечены, но помнить)

1. **Next 15.5.4 не собирает static export на Windows** — падает на ренейме `500.html`/`pages-manifest.json`. Лечится обновлением до 15.5.22.
2. **При static export заголовок `content-type` из route-handler теряется**: `/llms.txt` отдаёт nginx как `text/plain` **без** `charset`, кириллица превращается в кашу. Лечится только на стороне nginx (`charset utf-8` + `charset_types`). Коварно тем, что `.json` и `.html` при этом выглядят нормально.
3. **Смоук из GitHub Actions до российского хоста ненадёжен** — раннеры стоят вне РФ, `curl (28)` при живом сайте. Смоук перенесён на бокс, внешняя проверка не блокирующая.
4. **Внешний таймаут ≠ «сайт лежит»** — сперва сверь, куда указывает домен (история с ДК и Калинино: приложения работали, домены указывали в пустоту).
5. **fullPage-скриншот не ждёт `loading="lazy"`** — при проверке своего сайта puppeteer'ом надо прокрутить страницу, иначе снимет пустые рамки и решишь, что картинки сломаны.
