## Что найдено по дороге — три ловушки, которые стоит помнить

1. **Мутационная приёмка сканера прошла ЗЕЛЁНОЙ на примере ключа AWS из документации** (`AKIAIOSFODNN7EXAMPLE`): такие ключи в дефолтном allowlist gitleaks. Красный получен только на случайном токене (`generic-api-key`). Проверять сканер примером из документации вендора — не проверять ничего.
2. **В `deploy.yml` жил молчащий гейт.** Проверка юникод-хостов (G133/G134) шла как `grep -rlP … | head -1 | grep -q .` и могла проходить вхолостую двумя способами: под `pipefail` SIGPIPE инвертирует результат при НАЙДЕННОМ нарушении; а при недоступном `grep -P` (rc=2) последний grep не получал входа. Отказ был неотличим от успеха. Теперь коды 0/1/>1 различаются явно.
3. **Дважды правка делала ложью текст на самом сайте.** Метрика — утверждение главной «Счётчиков посещаемости, cookie и форм на этом сайте нет» в разделе «Честный статус вместо обещаний». Кадры Матрицы — подпись «ФИО сотрудников, контрагентов и номеров договоров на экранах нет и не будет». Оба переписаны. **Правило на будущее: меняя поведение сайта, грепни сайт на утверждения об этом поведении.**

## Грабли Метрики (проверено, не по памяти)

- **Информер проверяет Referer.** С localhost — **403**, без Referer и с прод-домена — 200 `image/png`. На локальном превью он выглядит сломанным ВСЕГДА; это не дефект вёрстки. Смотреть только на проде.
- **Информер отстаёт от отчётов на часы.** Кабинет уже показывал визит, а информер отдавал валидную картинку со всеми нулями. Ровно G237: приёмка только глазами по цифре, код ответа 200 ничего не доказывает.
- **G136 для Метрики невыполним.** Punycode-форму домена она дополнительным адресом не принимает («Неверный формат URL»), но IDN нормализует сама: фильтр адресов включён, в кабинете кириллический домен, визит с punycode-хоста засчитан. Одного адреса достаточно.
- Информер делает статистику сайта **публичной** — это следствие D-017, и об этом теперь прямо сказано на главной.

## Грабли прошлых сессий (помнить)

1. **Next 15.5.4 не собирает static export на Windows** — лечится обновлением до 15.5.22.
2. **При static export теряется `content-type` из route-handler**: `/llms.txt` без `charset` → кириллица в кашу. Лечится на стороне nginx.
3. **Смоук из GitHub Actions до российского хоста ненадёжен** — раннеры вне РФ. Смоук перенесён на бокс.
4. **Внешний таймаут ≠ «сайт лежит»** — сперва сверь, куда указывает домен.
5. **fullPage-скриншот не ждёт `loading="lazy"`** — прокрути страницу перед съёмкой.
6. **`out/` держится запущенным http-сервером** — `next build` падает с `EBUSY: rmdir`. Остановить сервер перед пересборкой.
